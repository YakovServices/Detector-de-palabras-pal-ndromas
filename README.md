# Detector-de-palabras-palíndromas
Este es un detector de palabras palíndromas hecho en Python3


**Manual:**

1. Ejecuta el script:
---------------------------------------------------------------
  Bash

     python3 Detector-de-palabras-palindromas.py

----------------------------------------------------------------

2. Escribe algo, si te devuelve tu palabra en rojo significa que no es palíndroma, pero si te devuelve tu palabra en verde es palíndroma.

3. Sígueme y estáte atento a nuevas releases y repositorios.
